Settings

Change the legacy demo login password for this browser. Account passwords are managed through each locally stored account. This does not provide server-level security.

User accounts & permissions

Admin lang ang puwedeng magtakda ng role. Ang Admin ay may full access; ang User ay makakagawa ng evaluation at makakakita ng sariling submissions; ang Viewer ay may access lang sa Dashboard at Evaluation History, view at print/export lamang, walang edit/delete at walang Settings.

Position evaluation questions

Pumili ng position para makita, maidagdag, mabago, o matanggal ang mga tanong na ginagamit sa evaluation.

I-edit ang mga tanong sa ibaba. Panatilihin ang bawat section title na nagsisimula sa # (hal. # 1. Organizational Skills). Isang tanong bawat linya sa ilalim ng title. I-click ang Save questions para ma-save.

Registered employees

Listahan ng mga nakarehistrong pangalan at designation. Puwedeng i-edit o i-delete ang bawat record.

Data backup

I-save muna ang backup sa computer bago mag-clear ng browser data o lumipat sa ibang device. Ang JSON backup ay may employee records, evaluation results, custom questions, at dagdag na evaluation names. Hindi kasama ang passwords.

This action cannot be undone. Gumawa muna ng backup.
